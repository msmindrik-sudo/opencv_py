# Thermal App — Тепловой фильтр с сохранением

Приложение для наложения тепловизорного эффекта на изображения с предпросмотром и сохранением результата.

## Возможности

- Загрузка изображения.
- Выбор палитры теплового фильтра:
  - Сине-красный (Jet)
  - Черно-красный (Hot)
- Автоматическое применение фильтра при смене палитры.
- Предпросмотр обработанного изображения.
- Сохранение результата в PNG или JPEG.

## Установка зависимостей

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python3 ThermalApp.py
```

## Использование

1. Перейдите на вкладку **Загрузка** и выберите изображение.
2. Перейдите на вкладку **Тепловой фильтр**.
3. Выберите нужную палитру в выпадающем списке — предпросмотр обновится автоматически.
4. При необходимости нажмите **Сохранить результат** и укажите путь для сохранения.
